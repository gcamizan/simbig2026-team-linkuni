Data and licence notes

  • Speech data: Mozilla Common Voice Spontaneous Speech 5.0, Puno Quechua, from the Mozilla Data Collective, released under CC0-1.0. Speakers are not identified, and the dataset is not re-hosted here.
  • Transcripts: produced by an ASR model fine-tuned for Puno Quechua in this project (Task 1), then corrected by a human reviewer.
  • English translations: generated with Meta's NLLB-200 (distilled 600M; licence CC-BY-NC 4.0, so this resource is non-commercial) using the Southern Quechua code quy_Latn, then edited by the reviewer. NLLB does not model the Puno variety exactly, so translations may contain errors.
  • Project: SIMBig 2026 shared task, team LinkUni. Educational resource.
